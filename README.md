# CodeQuest 🚀

A fun, beginner-friendly web application that teaches computer programming through interactive stories, missions, and gamification.

## Features

✨ **Interactive Learning**
- Story-driven lessons (2-5 minutes each)
- Simple, jargon-free explanations
- Python as the first language

🤖 **AI Tutor**
- Explains coding concepts in beginner-friendly terms
- Provides hints instead of answers
- Explains errors in plain English

💻 **Coding Playground**
- Write and run Python code
- Instant output display
- Helpful error messages

🎮 **Gamification**
- XP points system
- Levels and progression
- Achievement badges
- Daily streaks
- Progress tracking

📚 **Quizzes & Challenges**
- Auto-generated quizzes after lessons
- Multiple choice and coding challenges
- XP rewards for correct answers

🏰 **Story Mode**
- Fantasy adventure where coding solves problems
- Unlock new worlds and missions
- Progressive difficulty

📊 **Dashboard**
- Level and XP display
- Streaks and milestones
- Lesson completion tracking
- Badge showcase

## Tech Stack

**Frontend:**
- React 18+ with TypeScript
- Tailwind CSS for styling
- Framer Motion for animations
- Redux Toolkit for state management

**Backend:**
- Node.js with Express.js
- PostgreSQL for database
- JWT for authentication
- OpenAI API for AI Tutor
- Pyodide for Python execution

**Deployment:**
- Docker for containerization
- Ready for cloud deployment (AWS, Vercel, Railway)

## Getting Started

### Prerequisites
- Node.js 18+
- PostgreSQL 13+
- Python 3.9+

### Quick Start with Docker
```bash
git clone https://github.com/aditikhairnar3686-creator/CodeQuest.git
cd CodeQuest
docker-compose up
```

Access the application:
- Frontend: http://localhost:3000
- Backend API: http://localhost:5000
